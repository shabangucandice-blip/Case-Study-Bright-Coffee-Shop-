# Case-Study-Bright-Coffee-Shop-

I conducted an analysis project for Bright Coffee In March 2026, aiming to uncover insights from raw data provided. Using tools like Miro and Canva , Data Bricks (SQL) , Microsoft excel and Powerpoint , I uncovered some key findings. It appears Bright Coffee has potential for exponential growth if it the team focuses on their best-selling beverages / Products. Their extensive menu is diluting demand and morning sales  drive profit margins across all 3 locations, by adjusting focus and staffing to capitilise on peak periods, Bright Coffee csn unlock growth and expansion opportunities
